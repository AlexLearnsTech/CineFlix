# 🎬 CineFlix

Aplicativo desenvolvido no **MIT App Inventor** para pesquisar informações de filmes utilizando a **API OMDb**.

## 📱 Funcionalidades

- 🔍 Pesquisa de filmes pelo nome
- 🖼️ Exibição do pôster do filme
- 🎬 Exibição do título
- 📅 Ano de lançamento
- 🎭 Gênero
- ⭐ Nota IMDb
- 📝 Sinopse

## 🛠️ Tecnologias utilizadas

- MIT App Inventor
- OMDb API
- JSON
- HTTP Requests

## 📂 Arquivos do projeto

- **CineFlix.aia** → Projeto do MIT App Inventor.
- **CineFlix.apk** → Aplicativo Android pronto para instalação.

## 🚀 Como utilizar

1. Instale o arquivo **CineFlix.apk** em um dispositivo Android.
2. Digite o nome de um filme.
3. Pressione o botão **Pesquisar**.
4. Aguarde o carregamento das informações do filme.
